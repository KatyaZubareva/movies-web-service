# movies

Прототип веб-сервиса, который помогает выбрать фильм для просмотра сегодня вечером.

## Страницы

- **Каталог** — рекомендации на вечер, поиск, фильтры по жанру, длительности, годам и стране, подборки.
- **Страница фильма** — описание, рейтинги Кинопоиска и IMDb, актёры, награды, факты, отзывы и похожие фильмы.

## Как запустить

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Данные

10 фильмов с постерами. Информация собрана по карточкам Кинопоиска, IMDb и официальным источникам.
Избранное, лайки и отзывы хранятся в `localStorage` браузера.
